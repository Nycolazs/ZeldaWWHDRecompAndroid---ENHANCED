# v1.2 Enhanced — Hybrid touch layout, sun flare & haze, Japanese version, pause & 40 fps menu fixes

An update to the Enhanced fork of the Android port of The Legend of Zelda: The Wind Waker HD,
focused on playing on a single touch screen: the GamePad's touch menus now come up full screen
when you need them, and the pause and menu bugs some of you hit are fixed.

**The APK contains no game files, no game code and no keys.** It installs over v1.0 or v1.1 and keeps your
saves and settings. After updating, the first start compiles the game code on your device again
(a few minutes, once).

## Highlights

- **Hybrid layout (new).** *Options → Layout → Hybrid*: the TV picture full screen while you play,
  and the GamePad's screen full screen whenever a menu is open or you're outside the game (title,
  file select). Items, map, sea chart and save menus work by touch on a single screen; you're back
  on the TV picture as soon as the menu closes. While the GamePad's screen is up, only A, B and
  pause stay on screen, so the rest of the screen is free for the menu.
- **The game's controller select now sets up the app.** Pick *Wii U GamePad* or *Wii U Pro
  Controller* on the game's "Controller select" screen and the app's controls switch to match:
  no more "connect a Pro Controller" wait, and no more touch controls driving the wrong controller.
- **Pro Controller means TV only.** With the Pro Controller the app shows the TV picture only (the
  GamePad's screen is set aside in that mode anyway). Back on the GamePad, your own layout returns.

## Fixes

- **Pause sometimes didn't open, or the pause menu wouldn't close.** Quick taps on the touch
  buttons (shorter than one game frame) could get lost; every tap now reaches the game.
- **Error sound and a stuck pause menu in Pro Controller mode.** Touches on the GamePad's picture
  reached the game, which refuses touch in that mode (error sound) and could get stuck in its menu.
  In Pro Controller mode the game no longer receives GamePad touches.
- **40 fps: menus stuck half closed.** At 40 fps the GamePad's menu could freeze in the middle of
  its closing animation (GamePad screen half dimmed, every menu refused with the error sound), also
  on the way from the file select into the game. Menus, the title and the file select now run at an
  exact 30 fps in 40 fps mode, for a moment after they close too; gameplay stays at 40.
- **No sound after moving the game to the GamePad.** The game's audio for the GamePad's speaker
  wasn't played, so off-TV play ("Currently playing on TV" → move to GamePad) went silent. It now
  plays through your device.

## Graphics and game versions (from upstream v0.5)

- **Sun corona and lens flare are back.** The game checks whether the sun is hidden by reading the
  depth buffer; it now reads the GPU's, so the glare and flare show up as on the console.
- **Distance haze and bloom.** Render targets get a proper mip chain, so the haze over the sea and
  the bloom look right; this also removes the black lines some of you saw in shadows.
- **Japanese version supported**, besides the USA and European ones.
- The second Vulkan recording thread is now used only with the Qualcomm driver (it was slower and
  flickered on Turnip). `WWHD_RECORD_THREAD` still overrides it.

## Stability (from the original ZeldaWWHDRecomp project)

- **Fixed an intermittent crash at boot.** A surface copy could land in memory the game had already
  freed and reused when the renderer was running late; the copy now finishes before the game
  continues.
- Plain `char` is now signed on ARM64, as on the PC and Mac builds the game code is tested on.
- A safety check no longer reads back uncached GPU upload memory (very slow on some drivers).

## Smoother setup

- **First start on a touch-only device**: with no controller attached, the app starts with GamePad
  controls and the hybrid layout.
- **Controller disconnected**: the touch controls come back on their own, and gyro and rumble move
  back to your device.

## Installing

Install the APK over v1.0 or v1.1. New installs: see the v1.0 notes (disc image, disc key and
`common.key` in one folder, then *Extract from your disc image…*).

Requirements: Android 11 or newer, 64-bit ARM, Vulkan 1.1, about 2 GB of free storage and memory.
40 fps needs a screen with a 120 Hz mode (the option only shows there).

If the app crashes, please attach `captures/crash-YYYYMMDD-HHMMSS.log` from the app's folder
(`Android/data/org.wwhdrecomp.app/files/`) to your report.
